# Fadebook Online

## 📷 Preview

<img src="./assets/preview.png" width="100%" />

Modern landing page inspired by premium urban barbershop branding.

A modern barbershop booking platform designed to connect clients and barbers through a premium, fast, and visually engaging experience.

This project was built with a strong focus on:

* premium UI/UX experience
* modern design inspired by international trends
* scalable full stack architecture
* performance and responsiveness
* mobile-first experience

Fadebook aims to transform the traditional barbershop booking process into a modern digital platform where users can:

* discover barbers
* book appointments online
* explore haircut trends
* experience a unique and modern interface
